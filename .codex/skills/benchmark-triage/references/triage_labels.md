# Triage Labels

Use these labels with the current registry schema.

## Priority

- `P0`: anchor or outline-stabilizing paper
- `P1`: strong representative or comparison target
- `P2`: useful but not urgent
- `P3`: peripheral or backlog-only

## Queue Tier

- `now`: next `1-3` batches to read soon
- `next`: near queue after `now`
- `later`: visible backlog
- `hold`: intentionally parked

## Survey Role

- `anchor`
- `representative`
- `contrast`
- `peripheral`

## Useful `next_action` Values

- `read-batch`
- `deep-read`
- `review-card`
- `draft-section`
- `hold`

## Useful uncertainty tags for `triage_note`

Use short bracketed tags inside the note when needed:
- `taxonomy`
- `modality`
- `evaluation`
- `scope`
- `historical-placement`
- `outline-fit`
